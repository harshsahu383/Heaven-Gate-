# Funeral Services Lead & Associate Management System

Starter repository for an Android member app, a web admin/calling dashboard, and a shared Node.js API.

## Structure

- `mobile/` — Expo React Native Android app
- `admin/` — React + Vite admin web app
- `backend/` — Express API (MySQL-ready)
- `docs/` — initial product and setup notes

## Prerequisites

- Node.js LTS and npm
- MySQL 8.x
- Android Studio (for local Android emulator) or Expo Go for early UI testing

## Start each application

Each application has its own README with commands. Configure environment variables from each `.env.example` file before connecting to a database.

> This is a development starter, not a production-ready system. Authentication, verification, access control, data retention, and payment controls must be completed and tested before real customer data is used.
